# Desenvolvimento de Sistemas — SENAI CIMATEC

Repositório que reúne os projetos, atividades e avaliações do curso de **Desenvolvimento de
Sistemas do SENAI CIMATEC**, organizados por módulo. Ele mostra a evolução do aprendizado: da
lógica de programação em C++ até APIs REST com Spring Boot, aplicações web com JavaScript e
React e o Trabalho de Conclusão de Curso em equipe.

## Módulos

| Módulo | Conteúdo | Tecnologias | Período |
|---|---|---|---|
| [Módulo 1](modulo_1) | Lógica de programação; ideação e criatividade | C++, Canvas do Problema, pitch | ago/2025 – dez/2025 |
| [Módulo 2](modulo_2) | Banco de dados; Programação Orientada a Objetos; back-end com Spring Boot | SQL Server (T-SQL), Java 21, Maven, Spring Boot, Spring Data JPA, Swing | fev/2026 – ago/2026 |
| [Módulo 3](modulo_3) | Programação de aplicativos (front-end) | HTML, CSS, JavaScript, Bootstrap, React + Vite | ago/2026 – out/2026 |
| [Módulo 4](modulo_4) | Ainda sem conteúdo publicado | — | — |
| [FloraHub (TCC)](https://github.com/DataCanuto/florahub-team-repository) | Trabalho de Conclusão de Curso em equipe | UX/UI (Figma), documentação, integração com IA | ago/2026 – set/2026 |

## Evolução

```
Módulo 1            Módulo 2                                Módulo 3                    TCC
C++ (console)  →    SQL  →  Java POO  →  Spring Boot (APIs) →  HTML/CSS/JS  →  React  →  FloraHub
lógica, vetores,    modelagem   pilares da POO,   REST, JPA,          layout, DOM,     componentes   produto completo:
funções, structs    e consultas  coleções, streams camadas, padrões   Bootstrap        e estado      UX, IA, rede social
```
