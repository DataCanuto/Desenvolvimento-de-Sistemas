# Desenvolvimento de Sistemas: SENAI CIMATEC

Este repositório reúne as atividades, avaliações e projetos que desenvolvi no **Curso Técnico em Desenvolvimento de Sistemas do SENAI CIMATEC** (2025 a 2027, em andamento).

Ele está organizado por módulo do curso e mostra a minha evolução: da lógica de programação em C++ à orientação a objetos em Java, ao back-end com Spring Boot e aos bancos de dados.

## Módulos

| Módulo | Conteúdo | Status no repositório |
| --- | --- | --- |
| [Módulo 1](modulo_1/) | Lógica de programação (C++) e Ideação & Criatividade | Publicado |
| [Módulo 2](modulo_2/) | Java POO, projetos Spring Boot e Banco de Dados | Pastas criadas, conteúdo ainda não publicado |
| [Módulo 3](modulo_3/) | Programação de Aplicativos | Pasta criada, conteúdo ainda não publicado |

## Projeto integrador: Flora Hub

O **Flora Hub** é o projeto que acompanha o curso desde o 1º semestre (julho/2025). É um app para quem cuida de plantas: identifica a espécie por foto com IA e recomenda cuidados conforme o clima local.

- Código (backend Java 21 + Spring Boot + Spring AI e frontend Preact): [DataCanuto/FloraHub](https://github.com/DataCanuto/FloraHub)
- Repositório da equipe: [DataCanuto/florahub-team-repository](https://github.com/DataCanuto/florahub-team-repository)

## Tecnologias por módulo

- **Módulo 1:** C++ (estruturas condicionais e de repetição, vetores, funções, `struct`), compilação com g++.
- **Módulo 2:** Java, Spring Boot, banco de dados.
- **Módulo 3:** desenvolvimento de aplicativos.
