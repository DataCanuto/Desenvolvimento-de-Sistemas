# Módulo 3 — Programação de Aplicativos (Front-end)

Terceiro módulo do curso de Desenvolvimento de Sistemas (SENAI CIMATEC), de agosto a outubro de
2026. Foco no front-end: estrutura e layout com HTML e CSS, interatividade com JavaScript,
componentes com Bootstrap e a primeira aplicação em React.

Os projetos estão em [`programacao-de-aplicativos/`](programacao-de-aplicativos).

## Evolução dentro do módulo

```
HTML/CSS (div, layout, flexbox) → Bootstrap → JavaScript (DOM, sistemas) → React (componentes)
```

O projeto **HortiFruti Digital** mostra essa evolução: primeiro em HTML, CSS e JavaScript
(`sistema-vendas`) e depois em React (`hortifruti-react`).

## Como executar

- Páginas HTML: abrir o `index.html` no navegador.
- React:

```bash
cd programacao-de-aplicativos/hortifruti-react
npm install
npm run dev
```

## Competências desenvolvidas

- HTML semântico e CSS (box model, layout, flexbox)
- Componentes e grid do Bootstrap
- JavaScript com manipulação do DOM e lógica de sistemas
- Componentização com React e build com Vite
