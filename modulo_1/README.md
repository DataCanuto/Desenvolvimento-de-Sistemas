# Módulo 1 — Lógica de Programação e Ideação

Primeiro módulo do curso de Desenvolvimento de Sistemas (SENAI CIMATEC), de agosto a dezembro
de 2025: fundamentos de lógica de programação em **C++** e uma introdução a ideação,
criatividade e apresentação de soluções.

## Lógica de programação (`logica-de-programacao/`)

Programas de console em C++, do primeiro "Hello World" até sistemas com menus e structs. A
ordem abaixo segue a progressão dos conceitos.

| Atividade | Conceitos praticados |
|---|---|
| [Biblioteca iostream](logica-de-programacao/Biblioteca%20iostream%2001-01-2025) | Entrada e saída com `iostream` (Hello World) |
| [Par ou Ímpar](logica-de-programacao/Par%20ou%20Impar%2001-01-2025) | Condicionais e operador de resto |
| [Troca de Valores](logica-de-programacao/Troca%20de%20Valores%2001-01-2025) | Variáveis e atribuição |
| [Tabuada](logica-de-programacao/Tabuada%2001-01-2025) | Laços de repetição |
| [Atividade Vetor](logica-de-programacao/Atividade%20Vetor%2001-01-2025) | Vetores (arrays) |
| [Calculadora IMC](logica-de-programacao/Calculadora%20IMC%2001-01-2025) | Funções |
| [Conta Bancária com Funções](logica-de-programacao/Conta%20Bancaria%20com%20Funcoes%2001-01-2025) | Funções e menu de operações |
| [Avaliação prática: Biblioteca](logica-de-programacao/Avaliacao%20Pratica%20Biblioteca%20SENAI%2001-01-2025) | `struct`, vetores de registros, menus; cadastro de livros, alunos e empréstimos |
| [Avaliação: Locadora de Veículos](logica-de-programacao/AVALIACAO%20Locadora%20de%20Veiculos%2001-01-2025) | `struct` aninhadas, vetores de registros, menus; cadastro de veículos, clientes, locação e devolução |
| [Atividade Notas com Matriz](logica-de-programacao/Atividade%20Notas%20com%20Matriz%2001-01-2025) | Atividade não entregue (registrada no `NOTA.txt`) |

### Como compilar

Cada pasta tem um `compilar.bat` que usa o `g++`:

```bash
g++ "Aula010_Atividade02_Tabuada.cpp" -o "Aula010_Atividade02_Tabuada.exe"
```

## Ideação e criatividade (`ideacao-criatividade/`)

- **Canvas do Problema** preenchido (`.pptx`): estruturação de um problema, do público e da
  proposta de solução.
- **Pitch e apresentação**: links para a apresentação e o vídeo do pitch.

## Competências desenvolvidas

- Raciocínio lógico e decomposição de problemas
- Estruturas condicionais e de repetição, vetores, funções e structs em C++
- Compilação pela linha de comando com `g++`
- Definição de problema e comunicação de uma solução (Canvas e pitch)
