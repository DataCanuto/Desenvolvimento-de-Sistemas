# Lógica de Programação (C++)

Exercícios e avaliações da unidade de Lógica de Programação, em ordem de complexidade.

| Atividade | Conceitos | Arquivo |
| --- | --- | --- |
| Biblioteca iostream | Entrada e saída (`cin`/`cout`), variáveis | `Aula002_HelloWorld.cpp` |
| Par ou Ímpar | Condicional `if/else`, operador `%` | `Aula004_Atividade003_ParImpar.cpp` |
| Troca de Valores | Variável auxiliar, atribuição | `Atividade007_C++_PedroCanuto.cpp` |
| Tabuada | Laço `for` | `Aula010_Atividade02_Tabuada.cpp` |
| Calculadora IMC | Funções com parâmetros e retorno, menu com `switch`, classificação por faixa | `Aula016_IMC_Funcoes.cpp` |
| Conta Bancária com Funções | Funções, validação de saque e depósito, laço `do-while` | `Aula016_CaixaCorrigido.cpp` |
| Atividade Vetor | Vetores, cadastro e filtro de pares e ímpares | `Atv_Vetores.cpp` |
| Notas com Matriz | Atividade não entregue (ver `NOTA.txt`) | — |
| **Avaliação: Biblioteca SENAI** | `struct` (Livro, Aluno, Empréstimo), vetores de registros, cadastro, listagem e empréstimo | `programa_biblioteca.cpp` |
| **Avaliação: Locadora de Veículos** | `struct` (Veículo, Cliente, Locação), controle de disponibilidade, locação, devolução e listagem | `prova_logica-de-programacao.cpp` |

## Como executar

Cada pasta tem um `compilar.bat` (Windows) que compila com o g++. Em qualquer sistema:

```bash
g++ "arquivo.cpp" -o programa
./programa
```
