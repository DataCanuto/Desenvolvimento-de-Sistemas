# crud

CRUD de agendamento de aulas, com entidades para Aluno, Professor e Aula, cada uma com seu controller e repository.

## Conteúdo

- `controller/AlunoController.java`, `controller/AulaController.java`, `controller/ProfessorController.java`
- `model/Aluno.java`, `model/Aula.java`, `model/Professor.java`
- `repository/AlunoRepository.java`, `repository/AulaRepository.java`, `repository/ProfessorRepository.java`

## Como rodar

```bash
./mvnw spring-boot:run
```
