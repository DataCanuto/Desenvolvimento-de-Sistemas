# my-first-web-api

Primeira Web API completa desenvolvida durante o treinamento, já incluindo repository, controllers e documentação de endpoints via Swagger.

## Conteúdo

- `controler/UsuarioController.java`, `controler/WelcomeController.java`
- `model/Usuario.java`
- `repository/UsuarioRepository.java`
- `doc/SwaggerConfig.java`

## Como rodar

```bash
./mvnw spring-boot:run
```

Documentação Swagger disponível em `/swagger-ui.html` após iniciar a aplicação.
