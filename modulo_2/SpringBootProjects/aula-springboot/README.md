# aula-springboot

Primeiro projeto de estudo em Spring Boot. Foco na estrutura básica de uma aplicação (dependências, `application.properties`) e na criação dos primeiros models.

## Conteúdo

- `model/Pessoa.java`
- `model/Usuario.java`
- `model/Passaporte.java`

## Como rodar

```bash
./mvnw spring-boot:run
```
