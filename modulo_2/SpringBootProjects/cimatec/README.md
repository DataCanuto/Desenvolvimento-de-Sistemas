# cimatec

API para gestão de prontuários de pacientes, desenvolvida durante o curso SENAI/Cimatec.

## Conteúdo

- `controller/PacienteController.java`
- `controller/UsuarioController.java`
- `model/Paciente.java`, `model/Prontuario.java`, `model/Usuario.java`
- `repository/PacienteRepository.java`, `repository/UsuarioRepository.java`

## Como rodar

```bash
./mvnw spring-boot:run
```
