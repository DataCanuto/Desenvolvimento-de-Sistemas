# apicimatec

Evolução da API do Cimatec, com entidades para Cliente, Passaporte e Pedido. O código-fonte está em [apicimatec/](apicimatec).

## Conteúdo

- `model/Cliente.java`
- `model/Passaporte.java`
- `model/Pedido.java`
- `model/Pessoa.java`
- `model/Usuario.java`
- `controller/HomeController.java`

## Como rodar

```bash
cd apicimatec
./mvnw spring-boot:run
```
