# petshop-project

CRUD para gestão de um petshop, com entidades Tutor, Animal e Endereço.

## Conteúdo

- `controller/TutorController.java`, `controller/AnimalController.java`, `controller/EnderecoController.java`
- `model/Tutor.java`, `model/Animal.java`, `model/Endereco.java`
- `repository/TutorRepo.java`, `repository/AnimalRepo.java`, `repository/EnderecoRepo.java`

## Como rodar

```bash
./mvnw spring-boot:run
```
